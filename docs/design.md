# 设计规范

## 1. 设计目标

OpenDocs 是**效率工具**，不是营销站点。界面要让人把注意力放在内容上，而不是界面上。

四条原则：

1. **内容优先**：装饰性元素（渐变、插画、阴影）只在必要时出现，且强度克制。
2. **一致大于个性**：同一类信息在哪个页面都长一个样，降低学习成本。
3. **密度适中**：比消费类产品紧，比 IDE 松。列表行高 46px，正文 13–14px。
4. **可预期**：所有危险操作二次确认，所有异步操作有明确状态。

## 2. 明确不做的风格

这些是"AI 生成感"最集中的特征，本项目中一律避免：

| 避免 | 原因 |
| --- | --- |
| 蓝紫渐变、mesh 背景 | 与工具属性无关，且是最典型的模板化痕迹 |
| 大圆角 + 重阴影 + 玻璃拟态 | 削弱层次，长时间使用易疲劳 |
| emoji 当功能图标 | 跨系统字形不一致，正式感差 |
| 每个卡片都有悬浮上移 + 阴影增强 | 动效噪音，且暗示可点击但语义不明 |
| 三张等宽特性卡片堆在首页 | 营销模板，喧宾夺主 |
| 无意义的骨架屏/loading 动画 | 慢的时候才需要，快的时候只是闪烁 |

## 3. 设计 Token

集中在 `apps/web/src/ui/common.module.scss` 顶部，改一处即可全局生效。

### 3.1 颜色

| 语义 | 值 | 用途 |
| --- | --- | --- |
| `$primary` | `#3370ff` | 主按钮、选中态、链接 |
| `$primary-hover` | `#245bdb` | 主按钮悬停 |
| `$primary-soft` | `#eef3ff` | 选中项背景、标签底色 |
| `$text` | `#1b1f24` | 正文与标题 |
| `$text-secondary` | `#4e5969` | 次要文本、导航默认态 |
| `$muted` | `#86909c` | 元信息、占位符 |
| `$faint` | `#a9b1bb` | 最弱信息（分组标题、计数） |
| `$border` | `#e5e6eb` | 分隔线、卡片描边 |
| `$border-strong` | `#d5d8de` | 输入框、次级按钮描边 |
| `$bg` | `#f7f8fa` | 页面底色 |
| `$surface` | `#ffffff` | 卡片、顶栏、侧栏 |
| `$danger` | `#f53f3f` | 删除、错误 |
| `$success` | `#00b42a` | 成功提示、可用状态 |

所有中性色低饱和，保证长时间阅读不刺眼；品牌色只用于"可操作"与"当前选中"。

### 3.2 字体与字号

系统字体栈（`-apple-system` / `Segoe UI` / `PingFang SC` / `Microsoft Yahei`），不加载 Web Font。

| 层级 | 字号 | 字重 | 场景 |
| --- | --- | --- | --- |
| 首页主标题 | 40px / 1.25 | 600 | 仅首页 hero |
| 页面标题 | 18px | 600 | 文档管理、管理后台 |
| 卡片标题 | 14px | 600 | 首页入口卡 |
| 正文 | 13–14px | 400 | 列表、表单 |
| 元信息 | 12px | 400 | 时间、大小、位置 |
| 分组标题 | 11px | 500 | 侧栏 "目录" |

数字一律 `font-variant-numeric: tabular-nums`，保证时间、大小、用量纵向对齐。

### 3.3 间距

以 4 为基数：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 64`。
- 表单字段间距 18px，字段内 label 与输入 7px
- 卡片内边距 14–18px
- 页面内容区左右 24px，最大宽度 1160px

### 3.4 圆角与阴影

| Token | 值 | 用途 |
| --- | --- | --- |
| `$radius-sm` | 6px | 小按钮、导航项、标签 |
| `$radius` | 8px | 输入框、常规按钮 |
| `$radius-lg` | 12px | 卡片、面板 |
| 弹窗 | 14px | 对话框 |
| `$shadow-sm` | `0 1px 2px rgba(27,31,36,.06)` | 选中态、分段控件 |
| `$shadow` | `0 4px 16px rgba(27,31,36,.08)` | 下拉菜单、认证卡片 |
| `$shadow-lg` | `0 12px 32px rgba(27,31,36,.12)` | 模态框 |

阴影只用中性黑，不用彩色投影。

## 4. 布局

### 4.1 全局顶栏（52px）

```
[品牌] [文档管理] [本地白板]            [登录 / 头像▾]
```

- 品牌：已登录跳 `/documents`，未登录跳 `/`（首页）
- 当前路由的导航项用 `$primary-soft` 底色 + 品牌色文字
- 右侧：未登录显示「登录」主按钮；已登录显示头像圆形下拉（我的文档 / 管理后台 / 退出）

### 4.2 文档管理（侧栏 216px + 主区）

```
┌──────────┬─────────────────────────────────────────┐
│ + 新建    │ 我的文档 / 项目A        [搜索] [列表|卡片] │
│ 最近      │ ┌─────────────────────────────────────┐ │
│ 我的文档  │ │ 名称        所有者  位置   最近查看 大小│ │
│ 与我共享  │ │ ▣ 需求文档   我     项目A  2 小时前 12KB│ │
│ 收藏      │ │ ▣ 竞品分析   我     我的文档 昨天   8KB │ │
│ 回收站    │ └─────────────────────────────────────┘ │
│ 目录      │                                         │
│  ▸ 项目A  │                                         │
│  ▸ 归档   │                                         │
└──────────┴─────────────────────────────────────────┘
```

- 侧栏承载"位置"维度，主区承载"内容"维度
- 目录支持多级展开（▸/▾），最多视觉缩进 3 级后不再加深
- 视图切换结果写入 `localStorage`，下次进入保持一致
- 卡片视图用于快速浏览（封面/图标 + 标题 + 时间），列表视图用于批量管理

### 4.3 编辑器外壳

```
[← 返回] [类型标识] [标题输入框] [状态点] [导出] [分享]
──────────────────────────────────────────────
                 编辑器画布
```

- 标题内联可编辑，失焦保存
- 状态点四态：已保存（绿）、待保存/保存中（橙）、只读（灰）、错误/冲突（红）
- 免登录试用时，右侧显示「免登录 · 仅存本地」标签与「登录并保存」按钮

### 4.4 公开首页

首屏只有三块：一句话价值主张、两个按钮、五个编辑器入口。
不做多屏营销段落，功能入口就是首屏主体。

## 5. 组件规范

### 按钮

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| 主按钮 | 品牌色实底 | 每屏最多一个 |
| 次按钮 | 白底 + 描边 | 常规操作 |
| 幽灵按钮 | 无边框 | 工具栏、行内操作 |
| 危险按钮 | 红色文字 + 淡红描边 | 删除类 |

高度：常规 30–32px，小号 24–26px，首页 CTA 40px。

### 输入框

- 默认描边 `$border-strong`，聚焦时品牌色描边 + 3px 淡色光晕
- 错误信息用红底浅框，紧贴字段下方
- 禁用态灰底，不改变文字颜色对比度到不可读

### 列表

- 表头 36px、行 46px，行间 1px `#f2f3f5` 分隔
- 悬停整行变 `$surface-hover`，操作按钮**仅在悬停时出现**（减少视觉噪音）
- 名称列常显类型字标（板 / MD / W / X / P），颜色区分类型但不刺眼

### 标签

4px 圆角、11px 字号：`可用` 绿、`已停用` 灰、`已分享` 蓝、`已收藏` 灰。

### 弹窗

- 遮罩 `rgba(27,31,36,.45)`
- 头部 18px 内边距，底部操作区右对齐
- 危险操作在标题或正文中明确写出后果

## 6. 状态设计

| 状态 | 表现 |
| --- | --- |
| 加载中 | 居中一行"加载中…"，不用骨架屏 |
| 空列表 | 居中说明 + 指向"新建"的一句话引导 |
| 请求失败 | 页面顶部红色条，保留已有内容，不整页替换 |
| 保存冲突 | 状态点变红，提示"文档已在其它设备被修改" |
| 无权限 | 说明原因 + 跳转按钮（返回文档中心 / 去登录） |
| 操作进行中 | 按钮文案改为"保存中…"并禁用，防重复提交 |

## 7. 响应式

| 断点 | 变化 |
| --- | --- |
| ≤ 900px | 文档中心隐藏侧栏；列表视图只保留"名称 + 所有者"两列 |
| ≤ 720px | 首页导航折叠；hero 字号 40 → 28 |
| ≤ 600px | 白板保存按钮改为左下角贴边全宽 |

## 8. 已知缺口

- 前端**暂无暗色模式**（白板区域由 Drawnix 自理，已有 `[data-theme='dark']`）
- 列表不支持多选与批量操作
- 移动端仅做基础适配，未针对触屏优化拖拽与右键菜单

后续如补暗色模式，建议把现有 SCSS 变量改为 CSS 自定义属性，
在白板容器与 Web 页面容器上分别挂 `data-theme`，避免两套配色逻辑分叉。

# 功能说明

## 文档类型

| 类型 | 能力 | 导出 |
| --- | --- | --- |
| 白板 / 思维导图 | 无限画布、自由绘制、思维导图、插入图片、主题切换 | `.drawnix`、PNG/SVG |
| Markdown | 源码编辑 + 实时预览、插入图片、内嵌思维导图 | Markdown 源码、PDF |
| Word 文档 | 标题、列表、引用、表格、图片、高亮、对齐；可内嵌思维导图 | `.docx`、PDF |
| Excel 表格 | 多工作表、公式、选区、单元格格式 | `.xlsx` |
| 演示文稿 | 分页编辑、四种版式、背景色、配图 | `.pptx` |

所有文档都支持：自动保存、重命名、创建副本、移入回收站、恢复、永久删除、链接分享。

## 账号体系

- 邮箱 + 密码注册与登录，会话保存在 HttpOnly Cookie 中。
- 密码使用 PBKDF2-SHA256（10 万次迭代）哈希，数据库不存明文。
- 首个注册的账号自动成为管理员（可用 `BOOTSTRAP_FIRST_ADMIN=false` 关闭）。
- 支持邮箱验证、找回密码——需要在管理后台配置 Resend 邮件服务。

### 邀请制注册

管理后台 →「系统设置」勾选 **注册必须使用邀请码** 后，注册页会出现邀请码输入框。

邀请码在「邀请码」标签页创建：

| 字段 | 说明 |
| --- | --- |
| 邀请码 | 留空自动生成（10 位，去除 0/O/1/I 等易混字符） |
| 可用次数 | 1–10000，用完后自动失效 |
| 有效期 | 留空为永久；按日期选择，截止到当天 23:59:59 |
| 备注 | 记录给谁用，便于回收 |

名额扣减在 SQL 中原子完成（`used_count < max_uses`），并发注册不会超卖。
已用尽的码仍保留在列表中，可查看用量或删除。

## 目录与视图

- **多级目录**：侧栏「目录」区可新建、展开、重命名、删除。
  删除目录时，其中的文档会上提到父目录、子目录也会上提，不会连带删除数据。
- **最近**：按"最近打开时间"排序，没有打开记录时回退到更新时间。
- **收藏**：任意文档可收藏，独立视图汇总。
- **回收站**：软删除的文档在此，可恢复或永久删除（永久删除会一并清理对象存储中的正文）。
- **列表 / 卡片**：列表视图展示名称、所有者、位置、最近查看、大小；卡片视图适合快速浏览。
  选择会记在浏览器本地。

## 分享与协作

三种粒度：

1. **链接分享（只读）**：拿到链接的人可以查看，不能修改。
2. **链接分享（可编辑）**：未登录用户也能直接编辑并保存，适合外部临时协作。
3. **指定协作者**：按注册邮箱邀请，指定只读或可编辑，需登录后访问。

权限判定统一在服务端完成：所有者 > 协作者（editor/viewer）> 分享链接 > 无权访问。

## 免登录体验

- **本地白板**（`/local`）：完全离线，内容只存浏览器 IndexedDB，左下角可「保存到我的文档」。
- **试用模式**（`/try/:type`）：任选一类编辑器，草稿存浏览器；顶部「登录并保存」一键转为云端文档。

## 管理后台

| 模块 | 能力 |
| --- | --- |
| 概览 | 用户数、管理员数、文档数、存储占用、类型分布 |
| 用户管理 | 搜索、改角色、禁用、重置密码、删除（级联删除其文档） |
| 文档管理 | 跨用户查询、按类型/回收站过滤、删除 |
| 邀请码 | 创建、复制、启停、删除 |
| 系统设置 | 站点名称/URL、注册开关、邀请制、Resend、Turnstile |

## 与 Drawnix 的关系

白板内核来自开源项目 [Drawnix](https://github.com/plait-board/drawnix)（`packages/drawnix`，MIT）。
OpenDocs 在其之上补齐了账号、云端存储、目录、分享与管理后台；内核的对外 API 未做修改。

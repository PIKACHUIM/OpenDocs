# 使用教程

## 1. 第一次进入

打开站点会看到公开首页，首屏是五个编辑器入口。此时有两种走法：

- **直接试用**：点任意入口，进入免登录试用，内容只存在当前浏览器。
- **注册使用**：点右上角「免费注册」，注册后进入文档管理。

> 如果站点开启了邀请制，注册页会要求填写邀请码，向管理员索取即可。

## 2. 创建第一份文档

登录后进入 `/documents`：

1. 点左上角 **+ 新建**
2. 选择文档类型
3. 自动创建并打开，标题可直接在顶栏修改，失焦即保存

新建的文档默认放在"我的文档"（根目录）。如果当前正在浏览某个目录，会自动放进该目录。

## 3. 编辑与保存

- 编辑后 1.5 秒自动保存，顶栏状态点会依次显示「待保存… → 保存中… → 已保存」。
- 如果文档被其它设备改过，状态点变红并提示版本冲突，此时刷新页面取最新内容再改。
- 分享链接进入的只读文档，编辑器会隐藏工具栏并显示「只读」。

## 4. 组织文档

### 建目录

侧栏「目录」区域 → **+ 新建目录**。目录支持多级：在某目录下新建时，会自动成为它的子目录。

### 移动文档

文档行的 `⋯` → **移动到目录**，选择目标目录。选「我的文档（根目录）」表示移出到根。

### 收藏与最近

- `⋯` → **收藏**，之后可从侧栏「收藏」快速找到。
- 侧栏「最近」按打开时间排序，适合接着昨天的活继续。

### 视图切换

右上角「列表 / 卡片」可切换。列表适合批量管理（能看到位置、大小），卡片适合快速扫一眼。

## 5. 分享给别人

打开文档 → 顶栏 **分享**：

- **链接分享**：生成链接，选择「只读」或「可编辑」。
  - 只读：对方只能看。
  - 可编辑：对方即使没注册也能直接改，适合外部临时协作。
- **指定用户**：填入对方注册邮箱，选择只读/可编辑，对方登录后在「与我共享」里可见。

撤销分享：再次打开分享弹窗 → 撤销链接，旧链接立即失效。

## 6. 免登录试用后保存到账号

1. 首页点某个编辑器入口 → 进入试用
2. 编辑内容（自动保存在本地，关掉浏览器再回来还在）
3. 点右上角 **登录并保存** → 登录后自动把当前内容建成云端文档

如果只想留在本地，不点保存即可，不会产生任何云端数据。

## 7. 本地白板

`/local` 是一块完全离线的画布：

- 内容存在浏览器 IndexedDB，断网也能用
- 左下角 **保存到我的文档** 把当前画布转为云端文档
- 之后就在 `/d/:id` 里继续编辑、分享

## 8. 导出

打开文档 → 顶栏 **导出**：

| 类型 | 可导出 |
| --- | --- |
| 白板 / 思维导图 | `.drawnix`、PNG、SVG |
| Markdown | 源码、PDF |
| Word | `.docx`、PDF |
| Excel | `.xlsx` |
| 演示文稿 | `.pptx` |

导出库按需加载，不点导出不会下载对应代码。

## 9. 管理员日常

登录管理员账号 → 头像 → **管理后台**：

1. **概览**：看用户数、文档数、存储占用
2. **用户管理**：搜索用户、改角色、禁用、重置密码
3. **文档管理**：跨用户检索并清理
4. **邀请码**：创建邀请码（设次数与有效期），发给需要注册的人
5. **系统设置**：站点名称、注册开关、邀请制、邮件与人机验证

> 上线后建议把 `BOOTSTRAP_FIRST_ADMIN` 改为 `false`，避免库被清空时又自动产生管理员。
